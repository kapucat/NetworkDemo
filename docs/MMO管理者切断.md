# 管理者切断後のログイン画面への復帰

サーバーの管理者切断はWebSocketの1008（PolicyViolation）で通知する。
ゲーム側はこの通知で自動再接続を停止し、保持しているローカルのログイン情報を消してLoginSceneへ戻る。
通常の通信エラーによる切断は、従来どおり3秒後の再接続を試みる。
アカウントとランキング記録は削除しないため、ログイン操作から入り直せる。

## Unityでの確認

1. Unityに戻り、スクリプトのコンパイルが終わるのを待つ。
2. MMOへログインする。
3. 管理ツールの実サーバーの接続一覧を再読込みし、自分を選ぶ。
4. 「接続終了を確認」から理由と確認文字列を入力して実行する。
5. 対象のゲームがログイン画面に戻ることを確認する。
6. 3秒以上待っても勝手に接続し直さず、管理ツールの一覧から消えたままであることを確認する。
7. 同じアカウントで手動ログインできることを確認する。

ビルド済みのexeにはスクリプトの変更が反映されない。ビルド版を確認する場合は、利用者が再ビルドしたものを使う。
同じアカウントを複数のPC・ウィンドウで動かしている場合、対象の各クライアントに修正版が必要。
画面操作と再ビルドは利用者が行う。

## 実装

接続終了の通知を受けた時点で送信と再接続を抑止し、次のUpdateで認証情報の消去とシーン切替を行う。
保留中の再接続も抑止し、古いWebSocketから遅れて届いたイベントを新しい接続へ適用しない。
接続終了の説明はConsoleへ出力する。ログイン画面のデザインや新しいメッセージ表示欄は追加しない。
